# javascript-convenience-store-precourse

## 미션 - <편의점 🏪>

### 기능 요구 사항

구매자의 할인 혜택과 재고 상황을 고려하여 최종 결제 금액을 계산하고 안내하는 결제 시스템을 구현한다.

- 사용자가 입력한 상품의 가격과 수량을 기반으로 최종 결제 금액을 계산한다.
  - 총구매액은 상품별 가격과 수량을 곱하여 계산하며, 프로모션 및 멤버십 할인 정책을 반영하여 최종 결제 금액을 산출한다.
- 구매 내역과 산출한 금액 정보를 영수증으로 출력한다.
- 영수증 출력 후 추가 구매를 진행할지 또는 종료할지를 선택할 수 있다.
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.

### 기능 구현 목록

- [ ] 사용자 입력 받기
  - [x] 구매 상품, 수량 입력 받기.
    - [x] `Console.readLineAsync('구매하실 상품명과 수량을 입력해 주세요. (예: [사이다-2],[감자칩-1])')` 사용.
    - [x] 상품명, 수량은 하이픈(-)으로, 개별 상품은 대괄호([])로 묶어 쉼표(,)로 구분.
  - [x] 프로모션 미충족 수량 추가 여부 입력 받기.
    - [x] Y: 증정 받을 수 있는 상품을 추가한다.
    - [x] N: 증정 받을 수 있는 상품을 추가하지 않는다.
  - [x] 프로모션 재고 부족로 인한 정가 결제 여부 입력 받기.
    - [x] Y: 일부 수량에 대해 정가로 결제한다.
    - [x] N: 정가로 결제해야하는 수량만큼 제외한 후 결제를 진행한다.
  - [x] 멤버십 할인 적용 여부 입력 받기.
    - [x] Y: 멤버십 할인을 적용한다.
    - [x] N: 멤버십 할인을 적용하지 않는다.
  - [ ] 추가 구매 여부 입력 받기.
    - [ ] Y: 재고가 업데이트된 상품 목록을 확인 후 추가로 구매를 진행한다.
    - [ ] N: 구매를 종료한다.

<br>

- [ ] 결과 계산하기
  - [ ] 재고 관리
    - [x] 각 상품의 재고 수량 고려, 결제 가능 여부 확인.
    - [ ] 재고 파일(public/products.md) 최신화.
      - [ ] 구매할 때마다 결제된만큼 재고 차감.
  - [x] 프로모션 할인
    - [x] 오늘 날짜가 프로모션 기간 내에 포함된 경우에만 할인 적용.
      - [x] 오늘 날짜는 `DateTimes.now()` 활용.
    - [x] N개 구매 시 1개 무료 증정(Buy N Get 1 Free)의 형태
    - [x] 1+1 또는 2+1 프로모션이 각각 지정된 상품에 적용되며, 동일 상품에 여러 프로모션이 적용되지 않음.
    - [x] 프로모션 재고 내에서만 적용.
      - [x] 프로모션 재고를 우선적으로 차감하며, 프로모션 재고가 부족할 경우에는 일반 재고를 사용.
  - [x] 멤버십 할인
    - [x] 할인 금액: 프로모션 미적용 금액의 30% 할인.
    - [ ] 적용 범위: 프로모션 적용 후 남은 금액.
    - [x] 최대 한도: 8,000원.

<br>

- [ ] 결과 출력하기
  - [x] 환영 인사와 함계 상품명, 가격, 프로모션 이름, 재고 안내.
    - [x] `Console.print()` 사용.
    - [x] 재고 0일 시 `재고 없음` 출력.
    - [x] 상품 목록 파일 입출력으로 불러오기.
      - [x] `public/products.md` 파일 이용.
    - [x] 행사 목록 파일 입출력으로 불러오기.
      - [x] `public/promotions.md` 파일 이용.
  - [x] 프로모션 미충족 수량에 대한 안내 메시지 출력.
    - [x] `Console.print('현재 {상품명}은(는) 1개를 무료로 더 받을 수 있습니다. 추가하시겠습니까? (Y/N)')` 사용.
  - [x] 프로모션 재고 부족으로 인한 정가 결제 여부 안내 메시지 출력.
    - [x] `Console.print('현재 {상품명} {수량}개는 프로모션 할인이 적용되지 않습니다. 그래도 구매하시겠습니까? (Y/N)')` 사용.
  - [x] 멤버십 할인 적용 여부 안내 메시지 출력.
    - [x] `Console.print('멤버십 할인을 받으시겠습니까? (Y/N)')` 사용.
  - [ ] 영수증 출력.
    - [ ] 구매 상품 내역: 구매한 상품명, 수량, 가격
    - [ ] 증정 상품 내역: 프로모션에 따라 무료로 제공된 증정 상품의 목록
    - [ ] 금액 정보
      - [ ] 총구매액: 구매한 상품의 총 수량과 총 금액
      - [ ] 행사할인: 프로모션에 의해 할인된 금액
      - [ ] 멤버십할인: 멤버십에 의해 추가로 할인된 금액
      - [ ] 내실돈: 최종 결제 금액
  - [ ] 추가 구매 여부 확인 안내 메시지 출력.
    - [ ] `Console.print('감사합니다. 구매하고 싶은 다른 상품이 있나요? (Y/N)')` 사용.

<br>

- [x] 사용자 입력에 대한 예외 처리하기
  - [x] '[ERROR]'로 시작하는 메시지와 함께 Error를 발생.
  - [x] 예외 발생 시점부터 재입력.
  - [x] 구매할 상품과 수량 형식이 올바르지 않은 경우: `[ERROR] 올바르지 않은 형식으로 입력했습니다. 다시 입력해 주세요.`
  - [x] 존재하지 않는 상품을 입력한 경우: `[ERROR] 존재하지 않는 상품입니다. 다시 입력해 주세요.`
  - [x] 구매 수량이 재고 수량을 초과한 경우: `[ERROR] 재고 수량을 초과하여 구매할 수 없습니다. 다시 입력해 주세요.`
  - [x] 기타 잘못된 입력의 경우: `[ERROR] 잘못된 입력입니다. 다시 입력해 주세요.`
